## 5. Granular Unit Economics: Standard Batch Order Case Study

Below is the unit economics model for a typical **₹5,00,000 CNC Precision Machined Component Batch** (e.g., 250 units of SS 316L Valve Spindles with ground bearing journals):

```
+----------------------------------------------------------------------------------------------------+
|                                    TRANSACTION UNIT ECONOMICS                                      |
+----------------------------------------------------------------------------------------------------+
|  1. Buyer Purchase Order (100% Escrow Funded)                                      ₹5,00,000       |
|  2. Vendor Cost of Goods Sold (COGS Payout):                                     - ₹4,45,000       |
|     - Tranche 1 (Gate 1 - Certified SS316L Raw Material MTC):      ₹1,35,000                       |
|     - Tranche 2 (Gate 2/3 - 4-Axis CNC Spindle & Heat Treatment):  ₹1,80,000                       |
|     - Tranche 3 (Gate 4 - Final Inspection & Inward Clearance):    ₹1,30,000                       |
|  3. Gross Platform Take-Rate Revenue (11.0%)                                         ₹55,000       |
|  4. Direct Cost of Quality (COQ):                                                -  ₹14,000       |
|     - NABL Metallurgy Spectrometry (PMI / OES Test):                ₹3,500                         |
|     - In-House Metrology Engineer Time (3-Axis Zeiss CMM Probing):  ₹6,500                         |
|     - GPS Transport e-Way Bill Admin & Transit Marine Insurance:    ₹4,000                         |
|  5. Net Contribution Margin (74.5% of Revenue)                                       ₹41,000       |
+----------------------------------------------------------------------------------------------------+
```

### Capital Efficiency Advantages:
* **Negative Working Capital**: The buyer funds 100% into the nodal escrow account before raw steel is purchased. RKISPro carries **zero working capital inventory debt**.
* **High Net Contribution Margin (74.5%)**: Metrology costs scale with engineer density; once 3 shops in Chakan are inspected in a single circuit, per-order quality verification cost drops below ₹9,000.
* **Negative CAC via Repeat Orders**: Enterprise OEMs in Pune buy on quarterly blanket purchase orders. Once a machine shop is qualified, repeat order placement costs near zero.

## 7. Key Financial Controls & Risk Safeguards

1. **Escrow Stop-Payment Protocol**: Direct vendor advances are contractually prohibited. All funds reside in RBI nodal trust accounts. If a part fails Gate 2 or Gate 3, funds remain frozen, eliminating bad-debt write-offs.
2. **Marks Engineering & Co. Anchor Subsidy**: Co-founder Rupesh Tiwari’s active workshop absorbs initial prototyping fixture and tooling costs, saving ₹15L–₹20L in third-party job shop setup expenses during the first 6 months.
3. **Statutory Tax Alignment**: Automated SAC 9988 e-invoicing guarantees input tax credit (ITC) flow, insulating RKISPro from CBIC GST withholding risks.
